Exportar bancos a Moodle

Selecciona una o varias asignaturas, temas y subtemas. Descarga preguntas verificadas estructuralmente para importarlas al banco de preguntas de Moodle.

1. Seleccionar asignaturas

Puedes seleccionar varias. Cada asignatura se convierte en un archivo XML independiente; al elegir varias, se descargan juntas en un ZIP.

Cargando catálogo…

2. Seleccionar temas y subtemas

Se marcan todos los subtemas de una asignatura al seleccionarla. Puedes ajustar el contenido de varios temas; las selecciones se conservan aunque cierres los paneles.

Selecciona al menos una asignatura.

3. Configurar el archivo

0 = todas las seleccionadas. Si indicas un límite, se extrae una muestra aleatoria sin repetir preguntas de cada asignatura.

Las categorías se exportan como Asignatura → Unidad → Tema → Subtema. En Moodle, activa Obtener categoría desde el archivo al importar. Este módulo no crea cuestionarios automáticamente ni sustituye la revisión docente.

4. Validar y descargar

Esperando selección…

El XML contiene las respuestas correctas, las alternativas originales y las explicaciones. Importa siempre en el curso Moodle correspondiente. Los bancos de esta web son públicos; para exámenes confidenciales revisa la exposición de las preguntas y realiza una prueba de importación antes de una evaluación oficial.

Importación en Moodle

En tu curso de Moodle, abre Banco de preguntas → Importar, selecciona el formato Moodle XML, activa Obtener categoría desde el archivo y carga el XML correspondiente a esa asignatura. Si descargaste un ZIP, primero extrae los archivos XML. Después prepara el cuestionario oficial desde el banco de preguntas importado.
